## 🎯 核心特性

- 系统重装 / 初始化入口
- 跑分、IP 质量、解锁和路由测试
- 转发、Docker、安全优化常用脚本
- 执行前展示命令并确认

---

## 🚀 快速开始

```bash
bash <(curl -Ls https://vps.siaoz.si)
```

---

## ⚠️ 注意事项

- 请在可信 VPS 上以 root 执行。
- 涉及防火墙、SSH、重装、转发规则等操作前，建议保留一个现有 SSH 会话不断开。
